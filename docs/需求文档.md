## 2. 产品概述

### 2.1 产品定位

DataAI 是一款**全功能且支持 AI 的数据库管理桌面应用**，面向开发者和 DBA，在传统连接管理、SQL 执行、结果展示基础上，提供自然语言转 SQL、AI 辅助建表/改表等能力，提升数据库操作效率。

### 2.2 目标用户

- 开发人员：日常查库、写 SQL、建表改表
- 数据库管理员（DBA）：多库管理、结构同步、批量操作
- 数据分析/运营：在不太熟悉 SQL 的情况下，通过自然语言完成查询与简单表结构变更

### 2.3 核心价值

- **多库统一管理**：MySQL、PostgreSQL、SQLite、Oracle、SQL Server 等在一套界面中管理
- **AI 增强**：自然语言描述即可生成/执行 SQL，减少手写与记忆成本
- **设计一致性**：AI 建表/改表时参考现有表风格，保持库内命名与类型规范一致
- **易迁移**：支持从 Navicat 导入连接，降低从其他工具迁移的成本

## 4. 非功能需求

### 4.1 性能

- 连接与元数据加载应在数秒内完成，大量表时可采用懒加载或分页。
- SQL 执行与结果渲染需在合理时间内完成，大结果集考虑分页或流式展示。
- AI 请求应有超时与取消机制，避免长时间阻塞界面。

### 4.2 兼容性

- 支持 Windows 等主流桌面操作系统。
- Python 版本要求：>= 3.8。
- 各数据库需使用官方或常用驱动（如 PyMySQL、psycopg2、cx-Oracle、pyodbc 等）。

### 4.3 可维护性

- 核心逻辑与 GUI 分层清晰，便于后续扩展新数据库类型或新 AI 能力。
- 关键配置（如 AI 端点、提示词等）可配置化，便于调优与定制。

### 4.4 安全与隐私

- 连接密码等敏感信息不以明文形式记录在日志或截图中。
- 使用 OpenAI 兼容 API 时，用户需知悉数据会发送至所配置的 API 端点，本地模型则数据不出本机。

## 5. 用户场景简述

1. **日常查询**：选择连接 → 在 SQL 编辑器写 SQL 或输入自然语言 → 执行 → 查看/编辑/导出结果。
2. **快速建表**：选择数据库 → 打开 AI 建表 → 多轮对话描述表用途与字段 → 生成并执行建表 SQL。
3. **改表**：在树中选表 → 打开表结构编辑 → 用自然语言描述变更或直接改字段 → 预览并执行 ALTER。
4. **多库同步**：打开表结构同步 → 选源库与目标库 → 对比差异 → 选择要同步的表 → 生成并执行同步脚本。
5. **从 Navicat 迁移**：通过「从 Navicat 导入」自动检测或选择 .ncx 文件，批量导入连接后直接使用。
