# DataAI：一款值得推荐的AI驱动数据库管理工具

## 项目概述

**DataAI**（原名 db-ai）是一款基于 PyQt6 开发的现代化数据库管理工具，它巧妙地将人工智能技术与传统数据库操作相结合，为开发者和数据库管理员提供了一个高效、智能的数据管理解决方案。该项目由 codeyG 开发并维护，采用 MIT 开源协议，目前已发布到 v1.2.0 版本。

## 核心特性

### 1. 多数据库支持

DataAI 支持主流的数据库系统，包括：
- MySQL / MariaDB
- PostgreSQL
- SQLite
- Oracle
- SQL Server

这种广泛的数据库支持使得用户可以在一个统一的界面中管理不同类型的数据库，无需切换多个工具。

### 2. AI 智能 SQL 生成

这是 DataAI 最具创新性的功能之一。用户可以通过自然语言描述来生成 SQL 查询语句，AI 会自动：
- 分析数据库表结构
- 识别相关表和字段
- 生成符合数据库类型规范的 SQL 语句
- 智能识别枚举字段和约束条件

**智能表选择机制**：当用户在 SQL 编辑器中已有查询时，AI 会优先使用当前查询中的表，用户只需输入简短的指令如"只看active的"、"按时间排序"即可，无需重复指定表名。这种设计大大提升了交互的自然性和效率。

### 3. AI 辅助表结构管理

DataAI 的 AI 功能不仅限于查询，还延伸到表结构管理：

**智能识别现有表规范**：
- 自动分析数据库中已有表的结构
- 学习命名规范（表名、字段名风格）
- 识别字段类型选择习惯
- 理解主键、索引和约束的使用模式

**风格一致性保证**：
- 创建新表时自动参考现有表的设计风格
- 修改表结构时保持与整体数据库风格一致
- 减少人工规范检查的工作量

### 4. 查询结果直接编辑

DataAI 允许用户在查询结果表格中直接编辑数据，系统会自动生成并执行 UPDATE 语句。这个功能特别适合快速修正数据错误或批量更新少量记录。

**增强的数据编辑功能**：
- 支持在结果表中直接编辑单元格
- 支持多选行并批量删除
- 支持将单元格批量设置为 NULL
- 支持以 JSON 格式查看和编辑行数据或字段数据
- 所有修改会暂存，统一通过"保存"按钮提交到数据库

### 5. 服务器端分页查询

针对大数据集查询，DataAI 实现了智能分页机制：
- 自动为 SELECT 查询添加 LIMIT 保护（默认 100 行）
- 服务器端分页，每页默认 50 行（可调整 10-1000 行）
- 仅加载当前页数据，内存占用降低 90%+
- 完整的分页控件：首页、上一页、下一页、末页、页码跳转
- 自动执行 COUNT(*) 获取总行数

### 6. 便捷的连接管理

**从 Navicat 导入连接**：
- 支持从 Navicat 自动检测并导入连接配置（Windows）
- 支持导入 Navicat 导出的 .ncx 文件
- 大大简化了从其他工具迁移的工作量

**连接管理功能**：
- 添加/编辑/删除数据库连接
- 连接测试
- 连接列表管理

### 7. 表结构同步

DataAI 提供了表结构同步功能，可以在多个数据库之间同步表结构：
- 源数据库和目标数据库选择
- 表结构差异对比
- 批量同步多个表
- SQL 脚本生成
- 安全的变更预览

### 8. 表管理增强功能

**删除表功能**：
- 双重确认机制，防止误删
- 第一次确认：标准确认对话框
- 第二次确认：手动输入表名验证
- 明确警告"此操作将删除表中的所有数据，且无法恢复"

**表信息复制功能**：
- 连接信息和表名文本可选择复制
- 右键菜单"复制选中字段" - 复制选中的字段信息
- 右键菜单"复制所有字段" - 复制完整表结构
- 复制格式使用 Tab 分隔，可直接粘贴到 Excel

### 9. 多语言支持

DataAI 支持中英文界面切换，通过设置菜单可以轻松切换语言，满足不同用户的需求。

## 技术亮点

### 1. 现代化技术栈

- **GUI 框架**：PyQt6，提供现代化的用户界面
- **数据库访问**：SQLAlchemy，统一的数据库访问接口
- **数据验证**：Pydantic，确保数据格式正确性
- **AI 集成**：兼容 OpenAI API 格式，支持本地大模型（如 Ollama）
- **国际化**：自定义 i18n 系统，支持 JSON/TS 文件

### 2. 智能缓存机制

DataAI 实现了智能的表结构缓存系统，避免重复查询数据库元数据，提升响应速度。

### 3. 异步操作

关键操作（如查询、表结构同步、删除表等）都采用异步执行，不会阻塞用户界面，提供流畅的使用体验。

### 4. 错误处理

完善的错误处理和用户提示机制，当操作失败时会给出清晰的错误信息，帮助用户快速定位问题。
