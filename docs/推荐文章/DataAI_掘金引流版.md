# 还在把表结构复制到网页里问 AI？试试这台「本地数据库 + 人话查数」的 Windows 工具

> **一句话**：连上 MySQL / PostgreSQL / Oracle / SQL Server / SQLite 等库，用**中文描述需求**就能生成可执行 SQL；建表改表也能多轮对话，而且**记忆会跟着连接和库走**，越用越贴你的业务表。

我是开发者，也烦两件事：  
一是客户端里写 SQL 写到手酸；二是把 DDL 贴到各种网页里问 AI，心里不踏实。  

**DataAI（DB-AI）** 把「正经数据库客户端」和「大模型」放在**同一台电脑、同一套界面**里：自然语言查数、Agent 自动选表拉结构、支持 OpenAI 兼容接口和本地模型（如 Ollama）。下面用 2 分钟说清楚它凭什么值得你点开下载试用。

---

## 你先收这三个「爽点」

1. **说人话就出 SQL** —— Agent（LangGraph）会选表、拉 DDL、必要时查枚举，按**当前数据库方言**生成语句，不是通用废话。  
2. **建表 / 改表不毁风格** —— 参考库里已有表，尽量对齐命名、类型、主键和索引习惯，适合老项目里「再加一张表」。  
3. **长期记忆** —— 按连接 + 数据库记下命名规范、相似查询、表级摘要；提供「AI 记忆」面板可查看、清空或手动生成摘要。

此外还有：SQL 编辑器高亮与补全、多结果标签页、结果排序筛选与导出（CSV/Excel/JSON 等，以当前版本为准）、**从 Navicat 导入连接**（注册表 / `.ncx`），对从 Navicat 迁过来的人很省事。

---

## 适合谁？

| 谁 | 场景 |
|----|------|
| 后端 / 全栈 | 联调查数、复杂 JOIN 让 AI 起稿再改 |
| 数据同学 | SQL 不熟也能按业务口径问数 |
| DBA / 运维 | 多库管理、结构浏览与脚本工作流 |
