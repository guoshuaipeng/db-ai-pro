## 合规与账号说明

- 各站发帖应使用**你本人或团队官方账号**，并完成手机/邮箱/人机验证；**不应**由自动化工具代注册、代持号。
- Cursor 内置浏览器与本地 Chrome **会话不共享**，且无法代你收短信验证码；因此「打开网站自动发文」在未登录状态下无法完成发布。
- 若需 AI 辅助填表，可在**你已登录的浏览器**中自行粘贴正文；或使用上文脚本 + 环境变量在支持 API 的平台发布。
