## 四、按路径的标准步骤（Checklist）

### 4.1 MCP 协作（通用）

1. `list_pages` → 无写作页则 `navigate_page` 到清单中的写作 URL。
2. 若跳登录页：**你在该 Chrome 内登录** → 再 `navigate` 回写作页。
3. `take_snapshot` 定位**标题**控件 `uid`，`fill` 标题（标题 = `DataAI推荐.md` 第一行 `#` 后纯文本）。
4. **正文**：  
   - **思否类（CodeMirror）**：用 `evaluate_script` 对 `CodeMirror` 实例 `setValue` + `refresh`，并对隐藏 `textarea` 派发 `input`。  
   - **CSDN Markdown 编辑页**（`editor.csdn.net/md`）：**不要**对正文 `fill`；执行 `.\scripts\copy_recommend_md_to_clipboard.ps1`，在正文区 **Ctrl+A、Ctrl+V**。  
   - **CSDN 创作中心富文本**（`mp_blog/creation/editor`）：可对 iframe 内正文 `fill` 整段 Markdown，但**必须再「同步字数」**（见第七节），否则仍为「共 0 字」且无法发布。
5. 选标签 / 分类 / 原创 → 点发布 → `list_pages` 取文章详情 URL。
6. 把链接写回 [`多平台发布清单.md`](./多平台发布清单.md) 对应行。

### 4.2 CSDN Markdown（剪贴板，最稳）

1. 仓库根目录 PowerShell：`.\scripts\copy_recommend_md_to_clipboard.ps1`（或 `-FileName "xxx.md"`）。
2. 打开 `https://editor.csdn.net/md`（新建）；编辑已有文带 `?articleId=`。
3. 正文区聚焦 → **Ctrl+A** → **Ctrl+V** → 看右侧预览无误再发布。

### 4.3 脚本一键（可选）

见 [`scripts/README-发布脚本.md`](../../scripts/README-发布脚本.md) 中的命令与环境变量表。

## 五、踩坑摘要（不必每次重踩）

- **MCP `fill` 与 CodeMirror**：往往只改 DOM，不触发编辑器内部模型，**长文会丢格式**；CSDN MD 已明确用剪贴板或接口脚本。
- **MCP Chrome ≠ 日常 Chrome**：默认独立配置无 Cookie；要用日常登录态需按清单配置 `--autoConnect` 或调试端口（见清单第二节）。
- **发布后**：务必把**正式文章 URL** 写回清单，避免下次重复发。

## 七、CSDN 创作中心（富文本）— 已成功 MCP 流程（存档）

**适用**：必须用创作中心默认页发文（例如 `https://mp.csdn.net/mp_blog/creation/editor?not_checkout=1&spm=…`），且用 **Chrome DevTools MCP** 代填；正文为 **Markdown 源码**在富文本里当纯文本展示（与 MD 编辑页渲染不同，但可发通）。

**已成功一次的关键顺序**（`uid` 每次刷新会变，以当次 `take_snapshot` 为准）：

1. **前置**：MCP 已连到**有 CSDN 登录态**的 Chrome（见清单 `--autoConnect`）；`list_pages` → `select_page` / `navigate_page` 打开创作中心编辑页。
2. **标题**：读 `docs/推荐文章/DataAI推荐.md`，第一行 `# 标题` 去掉 `#` 后 `fill` 标题框。
3. **正文**：在快照里找到**正文 iframe / contenteditable**（往往在 iframe 内），将整篇 `.md` 文本 `fill` 进去（或分步写入，以页面可接受为准）。
4. **必做 — 同步字数与校验**：仅 `fill` 时，页脚常仍为「**共 0 字**」，点发布会弹「**请输入文章内容**」。任选其一：  
   - **键盘**：焦点在正文区 → 输入一个**空格**再 **Backspace**（或任意一次真实键入再撤销）；  
   - **脚本**：对 iframe 内 `contenteditable` `focus`，再 `dispatchEvent` `input` / `change`（与清单「创作中心富文本 iframe」条一致）。  
   确认页脚变为「**共 N 字**」（N 与正文长度大致一致）后再发布。
5. **摘要 / 标签**：填「文章摘要」；打开「添加文章标签」选标签（如人工智能、数据库）后关闭。
6. **发布**：点 **「发布博客」**；若侧栏「创作助手」挡交互，可先收起或再点一次。成功则跳 `https://mp.csdn.net/mp_blog/creation/success/<articleId>`，详情为 `https://blog.csdn.net/<用户名>/article/details/<articleId>`。
7. **收尾**：把正式详情 URL 写回 [`多平台发布清单.md`](./多平台发布清单.md)「已发布链接」列。

**与「剪贴板 + MD 编辑页」对比**：日常仍优先 **路径 A**（`editor.csdn.net/md` + `copy_recommend_md_to_clipboard.ps1`），编辑器会解析 Markdown；本节仅在必须走创作中心或 MCP 只能 `fill` iframe 时复用。
