# DataAI Desktop 更新日志

TypeScript / Electron 桌面端（`apps/desktop`）。本文件对应本机迭代里程碑；**1.0.0 为本地 RC**；后续小版本仍为本机迭代，尚未发布到 GitHub Releases。

## 3.62.0 — M101 折叠对象树

- 连接栏「折叠」与命令面板「折叠对象树」：收起所有库 / 表等节点，保留连接根展开（便于重新浏览）
- 若当前有树搜索，一并清除以便折叠立即可见；侧栏关闭时会先打开
- 不改动状态栏小地图、复制 JSON、聚焦结果区等近期能力

## 3.61.0 — M100 状态栏一键切换编辑器小地图

- 状态栏新增「小地图 / 小地图 关」芯片：单击切换 Monaco 小地图（与设置 / Ctrl+K「切换编辑器小地图」同源）
- 开启时高亮显示
- 不改动复制 JSON、聚焦结果区、状态栏只读 / 换行等近期能力

## 3.60.0 — M99 复制结果为 JSON

- 结果工具栏新增「复制 JSON」：将当前可见列与行（含选中行）复制为缩进 JSON 数组到剪贴板
- 超过 2000 行时截断并提示；命令面板「复制结果为 JSON」
- 与「导出 JSON」文件流程区分；不改动聚焦结果区、状态栏只读、复制 Markdown 等近期能力

## 3.59.0 — M98 聚焦结果区（Ctrl+Shift+2）

- 与 Ctrl+Shift+1 聚焦编辑器对称，便于键盘在编辑器与结果间切换
- 不改动状态栏只读、复制 Markdown、换行芯片等近期能力

## 3.58.0 — M97 状态栏只读 / 可写一键切换

- 悬停说明当前只读来源（全局 / 连接）；连接只读需在连接设置中关闭
- 不改动复制 Markdown、状态栏换行、复制输出、选区统计等近期能力

## 3.47.0 — M86 保存 / 打开 SQL 文件

## 3.42.0 — M81 Esc 取消正在执行的查询

- 查询执行中按 Esc 停止当前 SQL（与工具栏「取消」相同）；命令面板 / F1「取消正在执行的查询」
- 有弹层（命令面板、设置、转到行、连接对话框等）时 Esc 仍关闭弹层，不误取消
- 工具栏「取消」提示注明 Esc；快捷键说明同步
- 不改动转到行、收藏、展开恢复、NULL/空串、CSV BOM、选区运行等近期行为

## 3.41.0 — M80 转到行（Ctrl+G）

- 状态栏「行 · 列」可点击，打开同一对话框并预填当前光标
- Enter 确认、Esc 取消；超出文档范围时自动钳制到有效位置
- 不改动收藏保存、对象树展开恢复与结果格 NULL / 空字符串显示

## 3.40.0 — M79 一键收藏当前 SQL

- 编辑器工具行新增「收藏」：将当前标签 SQL 存为片段（全局或仅当前连接）

- 对话框预填名称（优先有意义的标签标题，否则首行 SQL）；Enter 确认、Esc 取消

## 3.33.0 — M72 实例库列表与勾选显示
