# DataAI Desktop 更新日志

TypeScript / Electron 桌面端（`apps/desktop`）。本文件对应本机迭代里程碑；**1.0.0 为本地 RC**；后续小版本仍为本机迭代，尚未发布到 GitHub Releases。

## 3.7.0 — M46 固定查询标签

- 查询标签右键：固定 / 取消固定、关闭、关闭其他、关闭右侧
- 固定标签靠左排列（组内保序）；会话恢复保留 `pinned`（baselineSql 仍不落盘）
- 关闭其他 / 关闭右侧跳过固定标签；未保存的未固定标签走 M45 确认
- 固定标签显示图钉样式；脏标记 • 与固定可并存

## 3.6.0 — M45 未保存标签关闭确认

- 相对打开/恢复/浏览基线跟踪脏状态；脏标签标题前显示 •
- 关闭脏标签或带脏标签关闭窗口：深色确认（继续编辑 / 丢弃更改）
- 会话恢复的内容视为干净基线；表浏览翻页会刷新基线

## 3.5.0 — M44 插入对象名到编辑器

- 对象树表/列：上下文菜单「插入表名 / 插入列名」；Alt 或 Ctrl（Mac：⌘）+ 单击亦可插入
- 表结构面板：表头「插入表名」、列行「插入」；列名 Alt/Ctrl+单击
- 按当前连接方言按需加引号（MySQL/MariaDB 反引号，其余 ANSI 双引号；普通标识符不引）

## 3.4.0 — M43 快速查询模板

- 工具栏「模板」与 Ctrl+K：内置 SELECT / COUNT / WHERE、各引擎表结构、INSERT/UPDATE/DELETE 骨架（约 9 条）
- 含 `{{table}}` / `{{limit}}` 等占位符时走现有片段变量填写框后插入编辑器

## 3.3.0 — M42 欢迎页 / 空工作区引导

- 无连接时展示深色欢迎面板：打开示例 SQLite、新建连接、导入连接、最近表/查询
- 有连接的回访用户不受影响；可选「不再显示欢迎页」

## 3.2.0 — M41 行选择 + 批量复制

- 结果表单击行号/单元格选择；Ctrl 多选、Shift 范围；高亮选中行
- 工具栏 / 右键：复制选中行为 TSV / CSV；IN / VALUES 作用于选中子集；Ctrl+C 优先复制选中 TSV

## 3.1.0 — M40 行注释切换 + 多光标说明

- Ctrl+/（及工具栏「注释」/ Ctrl+K）切换 SQL `--` 行注释；语言配置已含 lineComment
- F1 快捷键说明补充 Monaco 多光标（Alt+单击 / Ctrl+Alt+↑↓），沿用编辑器内置能力

## 3.0.0 — M39 编辑器小地图 + 字号

- Monaco 小地图可在设置 / Ctrl+K 开关（默认关闭）
- 编辑器字号 12–20，持久化；`updateOptions` 即时生效，无需整页重挂

## 2.9.0 — M38 应用内通知中心

- 标题栏「通知」：深色抽屉记录近期查询成功/失败、导入完成、连接探测失败（最多约 30 条）；可清空 / 单条移除；非系统托盘打扰
- 设置可选：仅错误通知、慢查询通知

## 2.8.0 — M37 窗口置顶 + 缩放快捷键

- 标题栏 / 设置 / Ctrl+K「置顶」切换始终置顶，偏好持久化
- Ctrl+= / Ctrl+- / Ctrl+0 调整 webContents 缩放；标题栏与状态栏显示百分比

## 2.7.0 — M36 表数据分页

- 打开表浏览时用 LIMIT/OFFSET（SQL Server 为 OFFSET/FETCH）分页，可选 100/500/1000
- 上一页 / 下一页、页码与总行数信息；深色分页条；当前页仍走结果虚拟滚动
- 自由 SQL 编辑后退出浏览分页模式；支持 SQLite / MySQL / PostgreSQL / SQL Server

## 2.6.0 — M35 连接分组 + 颜色标记

- 连接可归入命名分组（新建 / 改名 / 删除），树中可折叠
- 可选颜色圆点标记；随连接持久化

## 2.5.0 — M34 复制为 IN / VALUES

- 结果工具栏与右键菜单：复制列为 `IN (...)` 或 `VALUES`；正确处理字符串 / NULL / 数字
- 单元格 / 整行亦可复制为 SQL 片段

## 2.4.0 — M33 耗时条 + 慢查询标记

- 运行后结果区显示耗时 chip；超过设置阈值（默认 1000ms）标「慢」
- 历史记录展示耗时与慢标记；设置可改阈值

## 2.3.0 — M32 只读 / 安全模式

- 全局或单连接「只读」：拦截 INSERT/UPDATE/DELETE/DDL、单元格编辑、导入与样例填充；SELECT/EXPLAIN/导出可用
- 状态栏「只读」徽章；设置开关与 Ctrl+K 切换

## 2.2.0 — M31 窗格布局持久化

- 记住侧栏宽度、助手宽度、编辑器/结果分隔比例与开合状态

## 2.1.0 — M30 全局对象搜索

## 2.0.0 — M29 会话恢复（标签）

## 更早里程碑（M3–M9 摘要）

- **连接**：多连接、对象树、导入/导出连接包、示例业务库
- **编辑**：无边框深色 TitleBar、Monaco SQL、补全、多查询标签、Ctrl+K 命令面板
- **执行**：多引擎查询（SQLite / MySQL·MariaDB / PostgreSQL / SQL Server）、历史与收藏
- **Redis**：键浏览器（非 SQL）
- **AI**：自然语言转 SQL、修复、建表/改表助手（需配置兼容 OpenAI 的接口）
- **安全**：连接密码 / API Key 本机密封存储

Oracle / Hive 仅可保存连接，查询执行仍未接入。完整 ER 画布、Navicat 深度集成不在本 RC 范围。
