# DataAI Desktop 更新日志

TypeScript / Electron 桌面端（`apps/desktop`）。本文件对应本机迭代里程碑；**1.0.0 为本地 RC**；后续小版本仍为本机迭代，尚未发布到 GitHub Releases。

## 2.2.0 — M31 窗格布局持久化

- 记住侧栏宽度、助手宽度、编辑器/结果分隔比例与开合状态
- 分隔条拖拽更顺滑；尺寸钳制保证 1366×768 可用

## 2.1.0 — M30 全局对象搜索

- Ctrl+K / Ctrl+P 模糊搜索当前连接的表、列与收藏片段；Enter 打开查询 / 结构 / 插入
- 输入防抖；深色面板分区展示

## 2.0.0 — M29 会话恢复（标签）

- 跨重启恢复查询标签（标题 / SQL / 连接 id / 活动标签），最多 20 个；不含密钥
- 设置「启动时恢复标签」默认开启；连接缺失时标签标「断开」，不弹吓人错误

## 1.9.0 — M28 最近表 / 最近查询

- 记录最近打开的表与运行/收藏的查询（约 15 条），轻量持久化
- Ctrl+K 分区、标题栏「最近」、侧栏快捷入口

## 1.8.0 — M27 片段变量

- 收藏 SQL 支持 `{{table}}` / `{{limit}}` 等占位符；插入时深色表单填写并展开
- F1 快捷键说明与收藏空态提示文档化

## 1.7.0 — M26 导出 Markdown / HTML

- 结果工具栏导出 Markdown 表与简易 HTML（与筛选/排序视图一致）
- Excel / MD / HTML 共用行数上限（5 万），超出截断并提示

## 1.6.0 — M25 连接健康 / 延迟徽章

- 连接树显示延迟徽章（绿 / 黄 / 红）；菜单与 Ctrl+K 可手动探测；选中连接时自动轻量检测
- SQLite / MySQL / PG / SQL Server：`SELECT 1`；Redis：`PING`

## 1.5.0 — M24 AI 流式停止与进度抛光

- 生成中显示停止；中止 in-flight 请求并干净收尾，避免卡死转圈
- 深色卡片进度条 / 步骤高亮；本地预览无密钥仍可用

## 1.4.0 — M23 主题抛光 + 高对比度

- 收紧深色 token（hairline / focus / selection），减少壳层缝隙
- 设置「高对比度」开关（`data-contrast=high`），偏好持久化；密度舒适/紧凑保留

## 1.3.0 — M22 列排序 / 固定列 + 行号

- 结果表头点击排序（升序 / 降序 / 取消），与筛选、虚拟滚动兼容
- 最多固定 2 列横向滚动时保持可见；左侧 # 行号 gutter

## 1.2.0 — M21 收藏文件夹 + 结果筛选

- 收藏片段支持命名文件夹（新建 / 改名 / 删除）；片段可移动分组，持久化本机
- 结果表工具栏文本筛选（客户端，兼容虚拟滚动）

## 1.1.0 — M20 Schema Diff

- 表结构列级对比（可跨连接选两张表）：新增 / 删除 / 类型·可空·默认值差异
- 深色对比面板；可插入建议 ALTER/ADD SQL 到编辑器（执行仍走现有确认）
- 入口：表结构「对比结构」或 Ctrl+K「表结构对比」

## 更早里程碑（M3–M9 摘要）

- **连接**：多连接、对象树、导入/导出连接包、示例业务库
- **编辑**：无边框深色 TitleBar、Monaco SQL、补全、多查询标签、Ctrl+K 命令面板
- **执行**：多引擎查询（SQLite / MySQL·MariaDB / PostgreSQL / SQL Server）、历史与收藏
- **Redis**：键浏览器（非 SQL）
- **AI**：自然语言转 SQL、修复、建表/改表助手（需配置兼容 OpenAI 的接口）
- **安全**：连接密码 / API Key 本机密封存储

Oracle / Hive 仅可保存连接，查询执行仍未接入。完整 ER 画布、Navicat 深度集成不在本 RC 范围。
